# 🕌 Al Hasaniyyah Mobile & Portal Admin

Aplikasi Manajemen Alumni & Sistem Verifikasi Resmi **Ikatan Alumni Al Hasaniyyah Dalwa**.

---

## 🌟 Fitur Utama

- 📱 **Aplikasi Mobile Alumni (Expo / React Native)**:
  - Login Alumni berbasis Nama & Nomor Induk Anggota (NIA).
  - Kartu Tanda Anggota (KTA) Digital dengan QR Code Resmi.
  - Pendaftaran Alumni Baru online.
  - Pembayaran Iuran Wajib & Infak Beasiswa.

- 💻 **Portal Admin Pusat (Next.js & Vercel)**:
  - Dashboard Verifikasi Pendaftaran Real-Time.
  - AI Generator NIA Baku Format Resmi (`X.YY.ZZZZ.AAAAA`).
  - Fitur Import Massal Data Alumni dari Word/CSV.
  - Auto Send WhatsApp Notification ke Alumni.
  - Manajemen Iuran, Infak, dan Layanan Konsultasi.

## 🚀 Panduan Memulai

### 1. Menjalankan Aplikasi Mobile
```bash
cd mobile
npm install
npx expo start --web
```

### 2. Menjalankan Portal Admin Web
```bash
npm install
npm run dev
```
